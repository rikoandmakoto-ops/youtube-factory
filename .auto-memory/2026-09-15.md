切り抜きは「1分の元動画をそのまま出す」ので維持率が構造的に 70-90% に張り付き、
**高維持率帯が切り抜き系で埋まる → 帯平均が押し下がる。**

## 8. 環境メモ（作業効率に直結）

- **`pkill -f soffice` は自分自身を殺す。** bash -c のコマンド行に "soffice" が含まれるため
  `pkill` 自身がマッチして exit 137 になる。**`pkill -9 -f 'soffic[e]'` と書く。**（本日30分ロスした）
- **LibreOffice の recalc がマウント上で固まる。** 残留 `/tmp/OSL_PIPE_*` と
  `~/.config/libreoffice` が原因。**xlsx を `/tmp/<uniq>/` にコピーして recalc → 書き戻す**のが確実。
  マウント上の直接 recalc は 140秒でも終わらないことがある。
- **`.git/*.lock` は sandbox から unlink できない**（`Operation not permitted`）が **`mv` はできる。**
  git が lock を消せずに終了すると次の git が全部死ぬので、**`mv .git/index.lock .git/stale_locks/` して
  即座に次の git コマンドを打つ**。（09-11 の「Developerマウントは unlink 不可」と同根の問題が
  youtube-factory 側でも起きる。`.git/stale_locks/` は過去にも使われた形跡がある）
- 本日 `mcp__cowork__allow_cowork_file_delete` は定期実行で承認者がいないため自動却下された。
  **定期タスクでファイル削除に依存する手順を書かないこと。**
