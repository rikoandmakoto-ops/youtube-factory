# 相席マッチングアプリ 企画書

## コンセプト

居酒屋・バーで「会」同士をマッチングする相席アプリ。人単位ではなく会単位でマッチさせることで、グループ飲みの自然な出会いを促進する。

## ビジネスモデル

### ポイント経済圏

| 要素 | 内容 |
|------|------|
| 購入者 | 男性ユーザー（アプリ内課金） |
| 受取者 | 女性ユーザー（マッチ成立＋来店確認後に付与） |
| ポイント出口 | オリパサイトのポイントに変換 |
| 運営マージン | ポイント購入時20%＋変換時15% |

### ポイントフロー

```
男性: 1,000円 → 1,000pt 購入（運営マージン200円）
  ↓ マッチ成立
女性: 300pt 獲得（来店確認後）
  ↓ 変換申請
オリパpt: 300pt → 255オリパpt（変換手数料15%）
```

### 収益源

1. **ポイント販売マージン**: 購入額の20%
2. **ポイント変換マージン**: 変換額の15%
3. **未使用ポイント失効**: 有効期限6ヶ月（資金決済法準拠）
4. **プレミアム会員**: 月額制（優先表示、既読確認等）

## 機能一覧

### MVP（Phase 1）

#### ユーザー管理
- 会員登録（電話番号認証）
- プロフィール設定（年齢、性別、写真、自己紹介）
- 年齢確認（18歳以上必須、身分証アップロード）

#### 会の作成・検索
- 会を作成（店舗名、エリア、人数、時間帯、奢り/割り勘設定）
- 近くの会を検索（エリア、時間帯、人数フィルタ）
- 会のステータス管理（募集中、マッチ成立、終了）

#### マッチング
- 女性側: ポイント要求額の設定（1人あたり○pt）
- 男性側: 会の詳細確認 → リクエスト送信
- 女性側: リクエスト承認/拒否
- マッチ成立通知

#### ポイント
- ポイント購入（Apple Pay / Google Pay / クレジットカード）
- ポイント残高表示
- オリパポイントへの変換
- 取引履歴

#### チャット
- マッチ成立後のグループチャット
- 店舗・時間の調整

#### 来店確認
- QRコード / 位置情報による来店確認
- 確認後にポイント付与

### Phase 2（将来）
- レビュー・評価システム
- プレミアム会員
- 提携店舗ダッシュボード
- AI推薦（好みの会を提案）

## 画面構成

| 画面 | 内容 |
|------|------|
| ホーム | 近くの募集中の会一覧（カード形式） |
| 会の詳細 | 店舗、人数、時間、奢り設定、ポイント要求額 |
| 会を作成 | フォーム（店舗検索、人数、時間、設定） |
| マイページ | プロフィール、ポイント残高、履歴 |
| ポイント購入 | 金額選択、決済 |
| ポイント変換 | オリパptへの変換フォーム |
| チャット一覧 | マッチ済みの会のチャットリスト |
| チャット | グループチャット画面 |

## 法的考慮事項

| 項目 | 対応 |
|------|------|
| 出会い系サイト規制法 | インターネット異性紹介事業の届出が必要 |
| 年齢確認 | 18歳以上の確認義務（身分証提出） |
| 資金決済法 | ポイント有効期限6ヶ月、未使用残高1,000万円超で届出 |
| 特定商取引法 | アプリ内課金の表示義務 |
| 個人情報保護法 | プライバシーポリシー、利用規約の整備 |
| 風営法 | 相席を「あっせん」する場合の適用可能性を要確認 |
